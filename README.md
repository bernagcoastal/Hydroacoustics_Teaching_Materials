About this teaching package
This open-access teaching package introduces university students to underwater acoustics, hydrophone monitoring and ocean sound analysis using Python and real-world hydroacoustic recordings.

The materials are designed for self-directed learning and assume no previous knowledge of hydroacoustics or digital signal processing.

Students will learn how underwater sound propagates, how hydrophones record acoustic signals, and how to analyse recordings using waveforms, Fourier transforms, frequency filtering and spectrograms.
Teaching materials
The package consists of six units:
1. Introduction to Underwater Sound — Basic principles of sound and underwater acoustic signals.
2. Hydrophones and Ocean Sound Propagation — Hydrophone operation, sound speed, refraction and the SOFAR channel.
3. Signal Processing Basics — Sampling, Fourier transforms, filtering and spectrograms.
4. Identifying Ocean Sound Sources — Biological, anthropogenic and geophysical acoustic signals.
5. Applications of Hydroacoustics — Marine mammal monitoring, underwater noise and geophysical hazards.
6. Optional Extension Activity — Investigating the 2011 Tohoku earthquake.
The repository includes lecture slides and guided Jupyter notebooks with practical exercises, code explanations and interpretation questions.
How to use the materials
Begin with Unit 1 and progress through the slides in order. The Jupyter notebooks complement the theoretical units and provide opportunities to analyse real underwater recordings.

The notebooks use Python and open-source scientific libraries. Follow the installation instructions in Unit 3 before starting the practical exercises.

Download the notebooks and their associated datasets, keeping the required files together. Run the notebook cells sequentially using Shift + Enter.
Data and software
The materials use Python, Jupyter Notebook, NumPy, SciPy, Matplotlib and other open-source libraries.

Acoustic examples are drawn from Ocean Networks Canada and other scientific data providers. Original data sources are acknowledged in the corresponding materials.

Some third-party datasets may require separate access or permission for redistribution.
